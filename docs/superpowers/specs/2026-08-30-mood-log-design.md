# 心情记录（Mood Log）功能设计

- 日期：2026-08-30
- 项目：Folio（单文件 `index.html`，离线前端，GitHub Pages 部署）
- 状态：设计定稿，待实现

## 1. 概述

给 Folio 这个「工作/学习型」工具加一个**情绪与想法记录器**：一条随时可记的捕获入口 + 一个可回望的日历视图 + 情绪趋势。目标是让用户在辛苦的工作学习中能快速把「这一刻的心情」记下来（带精确时间），并能在往后的日子里一眼回看「哪天什么心情、情绪在怎么变」。

核心需求（与用户逐点确认后）：
- 记录**心情 + 文字想法**，每条带**精确时间戳**
- **随时**可记 —— 全屏任意页面常驻一个悬浮「记一笔」按钮
- **时间效应** —— 以**月历每天一色**为核心回望方式（用户选定），点开某天看当天全部记录
- 可随时查看**过往记录与情绪状态**
- 8 个可选心情，各自有颜色（经典 8 词·彩色，用户选定）
- 追加：**多日情绪折线图** + **心情趋势统计**（用户喜欢，从方案 C 并入）

## 2. 数据模型

存储键：`folio.mood`，一个 JSON 数组。每条记录：

```json
{
  "id": "m_1a2b3c4d",
  "ts": 1785564000000,
  "mood": "calm",
  "note": "今天实验终于跑通了，很难但不是坏的那种累"
}
```

- `id`：生成 id（`genId()`，与现有 docs 一致：`Date.now().toString(36)+随机`，前缀 `m_`）。
- `ts`：毫秒时间戳，用于排序、按天/月分组、显示 `HH:MM`。
- `mood`：8 个固定 key 之一。
- `note`：可选文字（想法内容），可为空字符串。

### 心情字典（8 个固定项，key → 视觉与情绪值）

每种心情配置 5 个属性，写进前端常量 `MOODS`：

| key | emoji | 词label | 主色(身份/选中/折线点/条) | 日历底色(柔) | 字色(在柔底上的文字) | score(情绪值) |
|---|---|---|---|---|---|---|
| `great` | 🤩 | 超棒 | `#B8860B` 黄金 | `#F7EDD0` | `#7A5A06` | 8 |
| `happy` | 😄 | 开心 | `#E4373A` 珊瑚红 | `#FAE2E3` | `#8F2B2C` | 7 |
| `calm` | 😊 | 平静 | `#2E9E5B` 翠绿 | `#E2F0E7` | `#1F5E3A` | 6 |
| `okay` | 😐 | 还行 | `#2B9EC4` 青蓝 | `#E2F0F5` | `#1B5E74` | 5 |
| `tired` | 😣 | 疲惫 | `#A050C8` 紫 | `#EEE3F6` | `#5F2E7E` | 3 |
| `irrit` | 😤 | 烦躁 | `#C1642E` 赭橙 | `#F6E4D7` | `#7A3A16` | 2 |
| `down` | 😞 | 低落 | `#3A72C7` 蓝 | `#E4ECF7` | `#234B8A` | 2 |
| `angry` | 😠 | 生气 | `#C93A44` 玫红 | `#F8E2E3` | `#7C242B` | 1 |

> **score（情绪值）**：把 8 心情映射到 1–8 的连续情感量表，用于折线图求每日均值与「本月平均」。允许并列（down/irrit 同为 2）。`great`=8 最高，`angry`=1 最低。

> **颜色校验**：主色集 （`#B8860B,#E4373A,#2E9E5B,#2B9EC4,#A050C8,#C1642E,#3A72C7,#C93A44`）已用 dataviz 校验脚本 `validate_palette.js --mode light` 验证：明度带、饱和度、与背景对比度(≥3:1)、正常色觉相邻对(最弱 ΔE 15.6) 全部通过。
> **已知接受的限制**：`great`(黄金) 与 `happy`(珊瑚红) 是一对语义相邻的暖色，色弱(色盲 CVD)下难分（ΔE 4.8）。这是为了同时保证「对比度 ≥3:1 + 语义正确」而无法再分离的物理极限。**处理方式**：不依赖颜色单独表意 —— 每种心情在日历格/条形图/折线点/选择 chip 中都是「颜色 + emoji + 词」一起呈现，色弱用户靠 emoji 与词区分，绝不只靠颜色。此点作为设计约束记录，不作为 bug。

### 健康与容量
- 记录数上限：保留最近 `5000` 条（超出时淘汰最旧，写入时做一次 trim）。避免 localStorage 被撑爆。
- 纳入现有【历史 → 导出 / 导入备份】，不另做一套存储出口。

## 3. 架构与组件

Folio 是单文件多 view 应用：`setView(v)` 用 `view` 变量在多个 `<section>` 间路由（editor / zip / imgpdf / pdf / repair / library / wordbook / map / focus / split）。本功能加一个**新 view 和一个常驻浮动按钮**，均沿用现有模式。

### 3.1 数据层
- `const MOOD_KEY = 'folio.mood'`
- `getMoodRecords()` / `setMoodRecords(list)`：读写 `localStorage[MOOD_KEY]`（JSON 数组），try/catch。
- `MOODS`：8 项常量数组（含上面 5 个属性 + score），按 label 顺序。
- `moodById(key)`：从 MOODS 找单项；找不到回退 `okay`。
- `addMoodRecord(mood, note)`：构造 `{id, ts, mood, note}`，unshift 前插入（或 push 后排序），`setMoodRecords` + trim 上限。
- `deleteMoodRecord(id)` / `updateMoodRecord(id, patch)`。
- `dayKey(ts)`：`YYYY-M-D`（本地时区），用于按天分组。
- `monthKey(ts)`：`YYYY-M`，用于月历定位。

### 3.2 心情页（新 view-tab「心情」）
导航栏新增一个 view-tab：`data-view="mood"`，标签文字「心情」，放在「专注」tab 之后。`setView` 增加 `mood` 分支（`moodTool.hidden = (v !== 'mood')` + 顶部标题/状态文案）。

section 结构（`<section class="mood-tool" id="mood-tool" hidden>`）：
- **概览条** `mood-overview`：一行数字卡
  - 本月记录数
  - 连续记录天数（有记录的天数最大连续段）
  - 今日心情（今天最后一条的 emoji+词；今天没记则显示「今天还没记」）
- **月历** `mood-cal`：
  - 周一起始 7 列网格；顶行周一至周日表头，6 行铺满当月
  - 每格 = 一天：有记录 → 用当天**最后一条**心情的「日历底色」填充 + 中置该心情 emoji；多条时右上角小徽标「×N」；没记录 → 淡灰虚框；今天 → 描边高亮
  - 上方翻页：`◀ 上月` / `下月 ▶` + `回今天`
- **当日明细** `mood-day-detail`：点击某天展开下方——该天全部记录列表，每条显示 `HH:MM + emoji 词 + 文字`，带「编辑/删除」按钮。点击空白或再点同一天关闭。
- **本月趋势** `mood-trend`：
  - **多日情绪折线图**：SVG。x=时间（最近 14 或 30 天，`周/月` 切换），y=情绪值 1–8（三个锚点词「低落 / 还行 / 超棒」）。每天 score = 该天所有记录 score 的均值（无记录的天跳过、连线不断开连接缺失段）。一条 2px 墨色细 `polyline`，每个数据点用当天心情的**主色**画圆点(≥8px)。hover 显示 crosshair + tooltip「日期 + 心情词 + 分值」。单轴。**这条折线固定跟随「最近 N 天」的真实记录，与月历当前浏览到哪个月无关**（折线把「情绪在最近怎么变」呈现给用户，不因翻月而跳变）。
  - **本月情绪分布条形图**：横向 `div` 条，每行一种心情（按 MOODS 顺序），条宽 ∝ **当前浏览月份**该心情条数，条色=该心情主色，行内直标「emoji 词 N」。条形间 2px 空隙。空月份显示占位文案。**分布条与顶部概览都跟随「浏览中的月份」**。

### 3.3 悬浮「记一笔」按钮（全屏常驻）
- 右下角固定圆角胶囊：`<button id="mood-fab">🌤 记一笔</button>`，`position: fixed`，常驻所有 view（编辑器/知识库/分屏/心情页均显示）。z-index 高于内容，低于 modal 遮罩。
- 点击打开 `mood-modal`：
  - 标题「记下此刻」
  - **8 个心情 chip**（单选，横向 wrap）：每个 chip = 主色圆点 + emoji + 词；选中态 = 主色描边 + 浅底色 + 轻微上浮。chip 有 `aria-label`（如「开心」），键盘可聚焦（tab 到 chip，空格/回车选中）。
  - **文字框** textarea 「写点什么…（可选）」，自动增高。
  - 底部：自动时间戳预览（如「2026-08-30 14:32」）+「保存」主按钮 +「取消」ghost 按钮。
  - 保存 → `addMoodRecord` → toast「已记录」；若今天已记 hint「今天已记 N 条」；关闭弹窗。
  - ESC / 点击遮罩 → 关闭（未保存内容丢弃）。
- 心情页里点击 FAB 也可（进入即见）。

### 3.4 全局 CSS 令牌
沿用现有 `--paper`(暖纸)、`--sheet`、`--ink`、`--ink-2`、`--muted`、`--hairline`、`--accent`、`--accent-soft`、`--ease`、`--font-display`、`--font-ui`、`--mono`。心情色一律用上表**十六进制字面量写死在 MOODS 常量**（只此一份，渲染处引用），不散落硬编码。胶囊/卡片阴影沿用「柔和阴影」体系（`0 1px 2px rgba(27,26,23,.04), 0 16px 44px rgba(27,26,23,.09)` 级别）。

## 4. 数据流

1. **记录**：FAB 点击 → modal → 选心情(+文字) → 保存 → `addMoodRecord` 写 `folio.mood` → toast。
2. **查看**：setView('mood') → `renderMoodView()`：读 `getMoodRecords()` → 计算 `今年月/本月`数据 → 渲染概览、月历、折线图、分布条、当日明细。
3. **编辑/删除**：点心当天记录的编辑/删除 → `updateMoodRecord`/`deleteMoodRecord` → 重新 `renderMoodView()`。
4. **切换月份**：`moodCal` 的翻页按钮改 `moodCalCursor`(当前显示的年月) → 重新渲染月历 + 该月概览/分布。**折线图不随翻页改变**（固定跟随最近 N 天），翻页只影响月历、概览、分布条。

## 5. 边界与错误处理

- **空状态**：无任何记录时，月历全空、折线图显示「还没有记录，点击右下角记一笔」、分布条显示占位。
- **无记录的天**：淡虚框，不显示颜色；不影响折线（跳过该点）。
- **同天多条**：当天校准即「最后一条」；明细列出全部；概览「今日心情」取最后一条。
- **localStorage 解析失败 / 异常**：`getMoodRecords` 返回 `[]`，页面显示空状态，不报错。
- **记录过多**：写入时 trim 到最近 5000 条。
- **键盘可达性**：日历格可用方向键在当天网格移动（实时高亮聚焦格），Enter 打开当日明细；chip 可实现单选组键盘导航；ESC 关弹窗；所有交互元素 `cursor: pointer`。
- **`prefers-reduced-motion`**：尊重，关闭非必要的过渡动画。
- **折线图单轴**：绝不双 y 轴；y 只做情绪值，与数量类统计（分布条）作为分离的两张图，不合并。

## 6. 测试要点

- 空状态渲染（无记录时各组件不报错）。
- 记一条 → 写 `folio.mood` → 重开页面仍在（持久化）。
- 同一天记多条 → 当天格子取最后一条心情 + 显示「×N」；当月概览/分布计数正确。
- 翻月/回今天：月历定位正确；跨年（12月→1月）边界。
- 折线图：有缺口（没记的中间天）连线正确；周/月切换；hover tooltip 出「日期+词+分值」。
- 删除/编辑：刷新后反映。
- 备份导出/导入：`folio.mood` 在导出/导入中，导入后记录恢复。
- 键盘操作 + focus 可见。
- 在校验过的暖纸背景下，各柔色格子的字色可读。

## 7. 非目标（YAGNI）

- 心情自定义增删（用户选的是「经典 8 词」，暂不做自增删；MOODS 常量预留扩展点即可）。
- 情绪导出为图片 / 分享；不做社交。
- 不做「时间胶囊回望」推送、不做专注与心情联动。
- 不做加密/登录/云同步（沿用本地 localStorage 现状）。
